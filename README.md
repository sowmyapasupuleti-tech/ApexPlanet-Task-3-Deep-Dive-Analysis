# ApexPlanet Internship – Task 3

## Deep-Dive Analysis & Interactive Dashboard

This project was completed as part of the ApexPlanet Software Pvt. Ltd. Data Analytics Internship – Task 3.

## Objective

The objective of this task was to perform a deep-dive analysis of the sales dataset, define core Key Performance Indicators (KPIs), and build an interactive dashboard to explore the selected business area.

## Deep-Dive Area

### Customer Segmentation Analysis

Customers were segmented based on age using business rules:

- Young: Age < 30
- Adult: 30 ≤ Age < 60
- Senior: Age ≥ 60

## Core KPIs

| KPI | Value |
|---|---:|
| Total Sales | ₹139.40M |
| Total Transactions | 1,000 |
| Total Quantity Sold | ~5K |
| Average Quantity per Order | 5.44 |
| Average Order Value | ₹139.40K |

### KPI Formulas

- **Total Sales** = SUM(Total_Sales)
- **Total Transactions** = COUNT(Order_ID)
- **Total Quantity Sold** = SUM(Quantity)
- **Average Quantity per Order** = Total Quantity / Total Transactions
- **Average Order Value** = Total Sales / Total Transactions

## Dashboard Features

The Power BI dashboard includes:

- KPI cards
- Sales by customer age segment
- Quantity sold by age segment
- Category sales by age segment
- Age Segment slicer
- Gender slicer
- City slicer
- Category slicer
- Interactive filtering and cross-filtering

## Key Findings

1. Adult customers contribute the highest sales among the three age segments.
2. Adult customers also account for the highest quantity sold.
3. Category contribution varies across different age segments.
4. Female customer sales total ₹66.94M, while male customer sales total ₹72.46M in the analyzed dataset.
5. Hyderabad records ₹9.46M in sales when selected through the city filter.
